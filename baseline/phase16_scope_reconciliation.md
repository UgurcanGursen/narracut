# Phase 16 Scope Reconciliation

Date: 2026-08-06
Decision: **Phase 16 benchmark foundation is authorized; external reference
media acquisition is not required for the first local package.**

## Accepted scope

The first package will add a deterministic, local benchmark contract that:

- derives only measurable editorial composition metrics from existing canonical
  executable-plan, EDL, render and audio-boundary artifacts;
- compares a named candidate snapshot with an immutable prior baseline and a
  declared, manually curated reference profile;
- emits canonical report bytes, deltas and explicit unavailable values rather
  than subjective “better” claims;
- binds every report to domain id, pack version and policy snapshot so a
  business-tech result cannot become a cross-domain production label.

## Explicitly excluded

- downloading, copying, decoding or redistributing third-party reference video;
- visual/semantic quality judgment, brand-style cloning or real viewer metrics;
- provider/source transport, queues, retries, UI labels, packaging and Phase
  17 product-gate behavior.

## Acceptance path

1. Define the closed metric schema and canonical baseline/reference/candidate
   identity boundary.
2. Independently audit the contract.
3. Implement the local reducer and adversarial tests.
4. Add business-tech reference profile fixtures and an immutable own-prior
   comparison.
5. Close Phase 16 only when every Roadmap metric is either derived or visibly
   unavailable with an owner; no unavailable value may count as success.

The three externally selected reference videos and the long-form real project
remain Phase 17 product-gate evidence, not a reason to fabricate Phase 16
results today.
